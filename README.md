Pada kesempatan kali ini saya akan menjelaskan tentnag program mini project kedua DDP yang dimana tema nya masih sama yaitu Pengeluaran Harian Mahasiswa yang digunakan untuk mencatat segala pengeluaran mahasiswa yang membantu mereka untuk tetap on track dalam pengeluaran. Program ini memiliki dua role yang dimana satu role merupakan admin yang memiliki akses penuh untuk melakukakn CRUD di dalam program terssebut dan satunya adalah pengguna atau member, yang dimana hanya dapat melihat catatan pengeluaran saja. Program juga menerapkan sistem library seperti prettytable dan pwinput dll. Tidak cuma itu, propgram juga punya isi seperti dictionary.

Flowchart menggambarkan alur kerja dari program phyton yang telah saya siapkan. Flowchaert dimulai dengan tampilan menu login yang dimana user dapat memilih ingin masuk sebagai pengguna biasa atau sebagai admin. Tidak cuma untuk admin atau pengguna biasa, program juga dapat menampilkan menu error jika ada data login yang salah. Hal itu dapat membuat user kembali ke menu login kembali dan hanya dapat lanjut jika user dan password sudah sesuai. Jika pengguna masuk sebagai admin, maka ia akan diarahkan ke menu admin yang dimana dia dikasih akses penuh untuk melakukan CRUD. Dan jka pengguna masuk sebagai user, ia hanya dapat melihat pengeluaran saja.
